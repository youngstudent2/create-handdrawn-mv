# 人体、手部与转场返修

## 1. 定位真正的问题

先读取现有工程、时间线与最终 MP4。将截图中的时间、字幕、服装和构图对应到镜头、A/B 原画、切换阈值及前后镜头。截图只标记了症状，不代表仅这一视频帧需要修复。

核对图片的实际模式以及渲染器是否将 RGBA 转成 RGB。纸底 RGB 图叠化时也会出现双重轮廓，但不能因此诊断为透明区域残留旧手臂或预乘 alpha 错误。

| 现象 | 先检查 | 对应处理 |
|---|---|---|
| 单张原画已有反关节、错手或多指 | 放大原始关键画 | 重画该姿势，并复核其配对图 |
| 原画正常，切换时出现两只手、双脸 | 是否同时绘制 A 与半透明 B | 更换姿势暴露方式，勿仅缩短溶解 |
| 脚漂移、站姿像翻纸片 | 全身旋转、缩放、网格、支点和地面 | 固定支撑关系，只动有依据的部位 |
| 做完动作突然退回再做一次 | 阈值分支、循环、局部时间与 easing | 修正非预期 B→A，保留有设计的回收动作 |
| 转场后人物突然补齐或位置跳变 | 遮罩终态、两镜头时间及锚点 | 修正覆盖范围与时间映射，检查编码后切点 |
| 片尾文字残留或压住衣服 | 独立文字图层及绘制调用 | 删除指定图层，检查多个片尾帧 |

保留未被指出且可用的素材、音乐和叙事。临时目录丢失时，先从已保存工程恢复，不直接要求用户重新上传所有素材。修改前确认当前版本，避免覆盖后来改动。

## 2. 先让动作成立，再生成漂亮画面

**全身。** 明确肩、胸腔、骨盆的方向，膝盖与脚尖方向，重心落点和支撑脚。转身、交叉腿、抬腿与回头同时发生，常会产生无法解释的身体扭转。两张图撑不起轨迹时，增加中间画；也可在保留镜头意图的前提下缩小动作，例如稳定站姿轻提丝带。不要把所有问题镜头退化为只眨眼的静态立绘。

**手。** 先指定有几个人、几只手、各自从哪侧进入、手掌朝上还是朝下、拇指在哪侧，以及哪里接触。正常结构是一拇指四手指；自然遮挡下不必五指全露。检查手掌宽度、指长比例、关节弯曲、指根连续性和手腕连接，不能只数指尖。

交握手指尤其容易生成额外手掌和融合指节。可用“指尖接近→轻放掌心”表达靠近；笑的镜头可用自然并拢的手指或下巴旁轻松握拳。按原叙事选动作，不把这些例子变成固定模板。手势简化仍须检查解剖，不能视为自动正确。

先修 A 并以原尺寸查看，再以 A 编辑 B。明确冻结画布、相机、头身比例、身体锚点与服装，只改该镜头需要的动作和表情。全身镜头还须冻结不应移动的脚位。保留同一角色风格，避免返修导致人物突然变高、头变小或线条变浓。

提示词中的“自然”“五指”“边距充足”不是验收结果。分别查看两张原画，再放进最终构图检查：头发、鞋子、手是否完整，手和字幕是否互相遮挡。

## 3. 防止把姿势切换做成重影

区分**同镜头的姿势暴露**与**不同镜头的场景转场**，不要共用一套万能交叉淡化。

- 小幅动作可按节拍直接替换，或在合理遮挡下换图。轮廓明显不同的手、手臂和身体，每帧优先只显示一张关键画。
- 不要先完整绘制 A，再把 B 的 alpha 从 0 加到 1；透明 B 覆盖不到的旧手臂仍会留在 A 中。正确 alpha 数学也不能消除两个不同肢体轮廓混在一起的语义重影。
- 大幅动作增加中间画或拆件表演；不能靠延长淡化、变形整个人物或光流强行让两张不兼容的图连续。
- 让姿势状态随本镜头时间按计划前进。检查所有阈值附近，尤其警惕为了“灵动”而加入的非预期 A→B→A→B。设计明确的眨眼或回收可以往返，但不能无意重复整段手势。
- 对落地角色，相机移动可整体改变取景，但身体运动须维持支撑脚与环境的关系。发梢、丝带、裙摆可独立微动，别把腿和脚一起正弦扭曲。

先让一个最难的返修镜头在合成中成立，再扩展其余镜头；别等所有原画生成后才检查锚点和动作幅度。

## 4. 让场景转场服务叙事

保留有用途的特效和景别变化；不以转场种类数量衡量质量。小幅姿势直切、大幅景别变化及情绪收束可选不同方式。温柔片段可用节拍直切和少量短纸色过渡，不需要每个切点旋转、缩放或虹膜。

需要避免两个人物同时混合时，可采用先淡至纸色、再从纸色显出下一镜：前半程 `mix(current, paper, ease(2*p))`，后半程 `mix(paper, next, ease(2*p-1))`。这里的 `p` 为转场区间 0–1，人物不直接互溶。约 0.16–0.18 秒只是在一次 30 fps 修片中使用的时长，须按音乐和画面测试，防止白闪突兀。

验证转场开始、中央、结束及下一帧。虹膜必须覆盖最远角落；滑动遮罩末帧须完全覆盖；提前绘制下一镜时须定义其局部时间，避免转场结束重置动作。短纸色过渡也不能掩盖错误解剖。

## 5. 文字与最终复核

- 将标题、叙事文字与片尾来源说明作为可独立开关的图层。用户要求删除底部文字时，删除对应绘制调用，保留未要求删除的标题；来源仍可记录在工程说明。文字已烘焙进图时，用图像编辑修复，勿裁损人物。
- 原尺寸检查每张修复图的手、腕、肘、腿、脚与服饰；总览只用于一致性。
- 播放修复镜头及相邻镜头，另从最终编码视频提取每个修改的姿势切点和场景切点前后至少三帧；核对动作先后、落脚、接触和双重轮廓。必要时逐帧扩大区间。
- 在片尾文字原本出现后的多个时间点检查，不能仅检查文字尚未淡入的首帧。保留用户未要求变更的总时长、画幅与音乐。
- 完整解码、24 张素材使用记录或 900 帧计数只能证明各自的技术属性。记录实际做过的原画检查、解码帧检查、视频播放与音频检查；环境无法播放时说明只完成逐帧核对，不宣称已观看整片或确认音画同步。
- 报告这是关键画合成/有限动画。生成了修正版不等于用户已认可，未经用户反馈不写“验收通过”。

交付前保存修正版成片和同步工程；更新现有文件时沿用其持久化身份及版本。提供实际可用的下载入口；若用户遇到下载失败，用环境支持且已验证的替代链接或传输方式，不编造链接、不反复发送同一个失效入口。
