# 分镜与成对立绘

## 从参考提取规则

按剪辑点抽帧，另取运动中段，记录一张紧凑表：时间、景别、主体动作、图层、相机、转场、音乐重音。抽帧只能说明外观；往返播放代表片段判断速度、停顿、先后关系与遮挡。

将风格写成能执行的规则，例如“米白纸纹背景＋冷色宇宙层”“角色动作后接同方向甩镜”“递归画框只作用于背景”。“高级、梦幻、丰富”不是可执行分镜。保留情绪逻辑，勿逐镜复制参考片的具体构图。

## 每镜头的最小信息

| 字段 | 要回答的问题 |
|---|---|
| `start` / `end` | 在最终时间线上何时出现？ |
| `character` | 该镜头是否有角色？全镜头双立绘要求下必须为 true。 |
| `framing` | 景别、画幅、完整身体部位、容许裁切？ |
| `action` | 角色由什么状态变成什么状态？ |
| `keyframes[].pose` | 每张的表情、视线、手势、轮廓具体是什么？ |
| `camera` | 相机运动如何配合动作？ |
| `layers` | 背景、角色、道具、前景如何分层？ |
| `effect` / `transition` | 效果为什么出现，保护哪些视觉重点？ |

JSON 模板中的镜头时间是最终剪辑区间，连续且不重叠；转场需要的前后素材余量在合成器里另行处理，不从总时长重复扣除。根据音乐选择节奏，不把 30 秒机械分成等长镜头。

## 姿势设计的判断

有效的 A/B 例子：

- A：双眼闭合，手在胸前；B：睁眼看向观众，一只手抬至脸侧。
- A：飞行前收肘蓄势、双膝弯曲；B：向飞行方向伸手、一腿展开。
- A：闻花；B：花降到胸口，另一只手向观众送出花瓣。

无效的“第二张”：同一姿势镜像、只移动到另一位置、只换背景或色调、重新保存一份 PNG。若只改变眼睛，也须足以支撑该近景镜头的表演；不能让所有全身镜头都只靠眨眼。

两张关键姿势是素材最低配置，不是连续动画的充分条件。遇到大幅转身、明显透视变化或复杂肢体轨迹，增加中间姿势、拆件动画或另选动画方法。不要把长溶解当作自然的肢体运动。

## 生成顺序与提示词

先确定 1–3 张清晰、相互一致的身份锚点，做一个有代表性的 A/B 对并在合成里试用，确认后扩展其余镜头。需要统一画风时反复引用同一锚点，而非让每个新镜头引用上一镜头，避免逐步漂移。

A 的提示词骨架（根据任务填写，不能留下占位内容）：

> 以所附角色设定为身份依据，制作该角色的独立透明背景立绘。保持【发型、眼睛、左右饰品、服装与配色】。采用【画风、线条、阴影、光向】。镜头【景别、角度、透视与画幅】。动作【A 的身体、手势、表情、视线】。完整保留【需要的身体部位】，轮廓离画布边缘留出可合成的空间。只含角色与指定手持道具，背景透明。

B 的编辑骨架：

> 以附图 A 为同一镜头的第一关键姿势，制作第二关键姿势。保持同一角色、服装细节、线条、光照、画布尺寸、相机角度和主体比例；头部/躯干锚点保持对齐。仅将【A 状态】改为【B 的明确动作、表情和视线】。保留透明背景和完整轮廓。手部解剖自然，每只可见完整手有五指，避免新增手臂、融合手指和道具穿插。

实际调用必须显式启用透明背景。提示词中的“透明”不能代替工具选项。使用编辑时遵循当前工具关于本地路径或最近图片引用的规则。记录真实调用内容，不把构思稿冒充已执行提示词。

## 检查与修复

- 身份：发色、发型、眼睛、左右发饰、腰饰和衣领是否一致；用“观众左侧/右侧”消除视角歧义。
- 解剖：逐张放大检查伸向镜头的手、交叉手指、胳膊与肩膀连接；自动计数无法可靠替代人工查看。
- 边缘：alpha 是否真实；是否有白底棋盘格画进像素；发梢、手指、鞋尖是否贴边或被截断。
- 配对：画幅、相机、头身比例与支点是否一致；B 是否真的贡献新的表演。
- 修复：优先重编辑问题图，保留已认可图；提示词承诺了边距并不代表生成结果实际有边距。
- 裁切：全身缺脚需要重做。胸像底边可由近景、画框或前景遮挡承接，不能作为完整悬浮人物放在场景中央。

拼图总览用于查一致性与缺失；按单图原尺寸检查手和边缘。只看总览会漏掉细节缺陷。
