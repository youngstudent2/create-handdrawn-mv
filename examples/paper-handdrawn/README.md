# 纸感手书原始修正版工具

原工程为 12 镜头 / 24 张关键画，30 秒、1920×1080。保留渲染器、分镜清单与来源辅助脚本；不包含角色、音乐、字体或参考视频。

在独立虚拟环境安装 `requirements.txt`，准备 FFmpeg、OpenGL 3.3+ / EGL。依赖版本沿用原工程记录，未验证所有平台安装情况。按 `python render.py --help` 查看参数。

## 必须自行准备的资源

渲染器使用 `assets/shot_XX_A.png` / `shot_XX_B.png`；第 07、10、11 镜改用 `assets/revised/` 下同名图片。还依赖 `assets/WenKai.ttf`、其他图层和音轨；完整相对路径以 `render.py` 为准。字体来源及原许可见仓库第三方说明。

`project.json` 可交给根目录 `scripts/check_project.py` 作计划检查。当前没有媒体，完整素材检查失败属于预期结果。渲染器是按具体画面硬编码的原工程，不会仅凭替换 JSON 生成任意手书。

## 来源辅助脚本

`get_sources.py` / `download_sources.py` 保留原始 Bilibili 示例地址，执行会访问外部网站并保存网页、元数据或视频，不要直接 import 它们当库使用。使用前自行改为有使用权限的来源，创建本目录 `references/`，并遵守平台访问要求及媒体许可。两脚本未在此次发布中联网运行，网页和接口变化可能令其失效；不保证下载成功，也不提供绕过限制的方法。

完整 GPU 渲染、音乐同步与原影片视觉验收未在此源码发布中复现。
